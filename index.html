7Compare Changesets

▾

Uses the separate Changed Elements API to compute exactly which elements changed between two changesets — element ids, insert/update/delete, and which categories of change. This is a different API from the tables above; enabling and running a comparison can take anywhere from a few seconds to a long time on large iModels.

Start must be an earlier changeset than End — the API rejects equal or reversed pairs. Start is exclusive (its own changes aren't included) and End is inclusive, so to see just one changeset's own changes, pick the changeset immediately before it as Start. Picking an End auto-fills Start with the previous changeset for you.
